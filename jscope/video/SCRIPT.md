# J-Scope tour — narration

Five beats. Every number is real, measured on Qwen3.5-4B with the Jacobian lens.

- **s0 — title** (~5s)
  This is a language model, mid-thought. Watch it think.

- **s1 — READ** (~18s)
  We ask for the currency of the country shaped like a boot. The prompt never
  contains the word Italy. But twelve layers deep, on the word boot, the concept
  Italy lights up — a quarter of the signal. The model has already solved the
  riddle, silently, before it says a single word.

- **s2 — WRITE** (~15s)
  If we can read a concept out of that space, we can write one in. Here the
  answer slot is empty. We inject the direction for France, right at the
  referent — and the model answers Paris. It never says France. It used it.

- **s3 — ERASE** (~15s)
  Is that concept really holding the answer? We erase Italy from those cells, and
  the model forgets. Euro, its top answer, collapses to nothing. The fact was
  living in that column the whole time.

- **s4 — MIX** (~20s)
  And we can remix it. Pull Italy down. Push Japan up. And the answer walks. Euro,
  gone. Yen, zero point two eight. Same prompt, every word unchanged. We reached
  into the model's mind and changed what it believes. This is J-Scope.
